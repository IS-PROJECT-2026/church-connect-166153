# Church Connect

Church Connect is a web application designed to help churches manage member engagement, communication, and community activities in one place.

## Features
- Church homepage
- About section
- Ministries
- Service information
- Events
- Event filtering
- Prayer request form
- Form validation
- Contact information
- Responsive mobile navigation

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
